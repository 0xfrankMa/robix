# Robix 改版设计：真实场景机器人数据采集（面向日本）

- 日期：2026-09-25
- 分支：`data-collection-pivot`（`main` push 即部署，改版完成前不合并）
- 状态：待用户审阅

## 1. 目标与背景

Robix（robix.one）原为湾区人形机器人维修平台。本次改版把**真实场景机器人数据采集**作为核心业务，维修降为附属。

- **读者**：日本的数据需求方（具身智能/フィジカルAI 团队、大厂研究所、大学实验室）。同事携网站在日本开拓客户。
- **网站要完成的事**：让日本潜在客户相信这支团队能在日本交付高质量真实场景数据，并愿意提交一次「相談」。
- **成功标准**：日本读者 10 秒内理解「这家能在真实场景采数据、数据管得住、已经与头部企业和研究机构合作过」，并完成 3 步咨询表单。

## 2. 战略约束（所有文案与素材必须遵守）

1. **弱化中国元素，但不造假。** 团队的采集设施经验不写地点；影像图注只写场景类型或「チームが運営する採集施設」，**不写成、不暗示位于日本**。被问及时由同事如实说明。
2. **日本还没有采集中心，直说。** 用两阶段表达：
   - 今すぐ：お客様の現場での出張採集（穿戴式设备可立即交付）
   - 次：日本採集拠点，招募首批合作方共同设计场景（时间表待用户提供）
3. **只写属实的承诺。** 数据管理条款仅限用户确认的 1–6 条（见 §6）。ISO 27001 不写。
4. **日本合作方暂不出现在网站上。**
5. **不放运营数字**（采集时长等），以协作实绩 logo 代替。

## 3. 语言

- 日语（默认）+ 英语，右上角 `JA | EN` 一键切换。
- 实现：一套 HTML，文本节点带 `data-i18n="key"`，字典放在 `assets/i18n.js`（`{ja:{...}, en:{...}}`）。语言选择写入 `localStorage`，URL 参数 `?lang=en` 可强制指定（方便同事发英文链接）。`<html lang>` 同步切换。
- 首屏无 JS 时显示日语（HTML 里直接写日语原文作为默认内容）。
- 上线前日语文案须由母语者（同事）审校。

## 6. 数据管理承诺（仅这 6 条，均经用户确认属实）

1. **国内保管**：日本客户的数据保存在日本境内的数据中心，不向日本境外传输。
2. **所有权**：采集数据及其衍生物归客户所有；Robix 不用于自身模型训练，不向第三方提供。
3. **隔离**：客户间物理与逻辑隔离，按项目独立存储，访问权限最小化。
4. **合规**：遵守个人信息保护法（APPI）；画面中人脸可打码；现场人员事先签署同意书。
5. **合同**：可先签 NDA；合同明确保管期限与删除义务。
6. **删除证明**：项目结束或客户要求时删除数据并出具删除证明。
